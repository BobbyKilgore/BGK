# BGK | Bobby G Kilgore — Technical Portfolio A static, dependency-free personal portfolio for `https://bobbykilgore.github.io/`. ## Features - Responsive, keyboard-accessible **hamburger navigation** for mobile - **Dark / light toggle** in the top-right of both pages; persisted in localStorage (default: dark) - Home, About, Expertise, Experience, Projects, Credentials, and Contact sections - Printable HTML resume with **Print / Save as PDF** control - Automatic portrait and screenshot placeholders while assets are absent - GitHub Pages-ready; no build, framework, external fonts, analytics, or third-party code - Basic Content Security Policy for a static site ## Preview locally From the unzipped folder: ```bash python -m http.server 8000 ``` Open http://localhost:8000 . A simple local static server is recommended for checking asset loading and links. ## Deploy when the personal GitHub account is ready 1. On the `BobbyKilgore` account, create a **public** repository named **`BobbyKilgore.github.io`**. This is a *personal account* repo, NOT a BlitzWare Solutions repo. 2. Upload the *contents* of this folder to the repo root (`index.html` must sit at root). 3. In the repository Settings → Pages, configure **Deploy from a branch** → `main` → `/(root)` and Save, if not already configured. 4. Open `https://bobbykilgore.github.io/` when Pages publishes. The repo is not created or modified by this starter package. ## Add the photos and application screenshots The following filenames are automatically recognized by `assets/js/app.js`: ```text assets/images/profile.jpg assets/images/blitzthreat.png assets/images/blitzrag.png assets/images/blitzweather.png assets/images/blitzgate.png ``` The placeholders remain visible until their corresponding file is available. See `assets/images/README.md` for dimensions and redaction guidance. ## Before publishing - Confirm employers, role titles, dates, and accomplishments in `index.html` / `resume.html`. - Confirm all credential dates and validity, especially expired or historical certifications. Present DoD 8570 IAT II as a historical qualification, not a standalone current certification. - Add your portfolio photo and real screenshots only after redacting customer information, secrets, internal paths, IP addresses, and other sensitive data. - Decide whether to add direct email, phone, or LinkedIn; the starter **intentionally does not disclose** private contact information. - All public demo links should be clicked and tested. A live BlitzThreat URL is included; other projects are clearly labeled in development or design. - Employer names are **text** in the UI. Use official logos sparingly and only under appropriate trademark usage guidelines; don't imply endorsement. - Official certification art/badges should only be added if you hold the credential and permitted-use conditions are met. - If you later distribute the code as an open-source template, add a license deliberately. Public GitHub source is not automatically open source. ## Structure ```text index.html resume.html .nojekyll README.md assets/ css/styles.css js/theme-init.js js/app.js images/favicon.svg images/README.md docs/README.md ``` ## Design notes - Colors, type sizes, spacing, and breakpoints live in `assets/css/styles.css`. - Theme persistence key: `bgk-theme-v1`. - JavaScript is progressive enhancement: page content remains accessible if JS is unavailable; only menu/theme/image swaps require it. - No contact form is included because GitHub Pages does not process server-side form submissions by itself.
